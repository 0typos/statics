# statics brand

The mark treats the toolkit as a rugged field case: the terminal is always available,
and the smaller diagnostic modules travel with it. Cyan defines the case and its active
tools; amber and magenta are small status signals. The deep-ink tile keeps the mark
legible on both light and dark surfaces.

## Assets

| asset | use |
|---|---|
| `statics-mark.png` | README, social cards and project listings |
| `statics-icon-128.png` | Compact repository, launcher or package icon |

Both files are opaque PNGs. Keep the deep-ink background intact; it is part of the mark.
Do not upscale the master.

## Palette

| name | hex | role |
|---|---|---|
| deep ink | `#071526` | Background and high contrast |
| signal cyan | `#00CFE8` | Case, tools and trusted information |
| probe amber | `#FFB000` | Active work and attention |
| state magenta | `#FF1688` | Endpoint state and faults |

Use cyan as the dominant accent. Amber and magenta should remain small enough to read
as signals rather than decoration. Keep the lowercase `statics` name as live text
instead of baking a wordmark into the image.
